# 会话统计弹层对齐 DeepSeek：布局紧凑化、TPS 行、速度趋势折线图

## Goal

会话统计（活动）弹层对齐 DeepSeek 的信息密度与视觉表达：补齐「输出速度（TPS）」行并让弹层内速度数字走与底部状态条一致的色阶；速度色阶「极快紫」锚点从 2000 tok/s 压缩到 500 tok/s；趋势图从裸柱状图重做为带网格参考线与数值标注的 SVG 折线图，消除弹层底部大片留白。

## 背景

实机对比 DeepSeek 会话统计弹层暴露三个差距：

1. **布局**：活动弹层的「最近速度趋势」区域是一块 36px 高的空白——柱状图高度按 `(tokPerSec / 2000) * 100` 百分比计算且下限 4%，38 tok/s 的柱子仅 ~1.4px，整块区域读起来就是底部留白；同时时长显示为 `577.68s` 裸秒数，DeepSeek 是 `12分4秒` 的人类可读格式。
2. **TPS 缺失**：DeepSeek 弹层有「输出速度（TPS）120 tok/s」行，本弹层只有模型用时/工具用时/首字延迟三行；且弹层内数字不上色阶，与底部状态条的速度数字颜色不一致。
3. **色阶阈值**：`ramp.js` SPEED_ANCHORS 为 0 红 → 150 绿 → 800 蓝 → 2000 紫，常见会话速度（几十~几百 tok/s）永远到不了紫色，蓝紫段形同虚设。

## Requirements

### R1 布局紧凑化（对齐 DeepSeek）

- 趋势图区域不再出现视觉性空白：图表本体必须填充其容器高度，留白仅来自图表自身构图。
- 弹层内时长格式对齐 DeepSeek 人类可读格式：`< 60s → X.X秒`、`≥ 60s → X分Y秒`、`≥ 1h → X时Y分`（毫秒级保留 `Xms`）；模型用时/工具用时/首字延迟三行统一套用。

### R2 输出速度（TPS）行

- 活动弹层新增「输出速度（TPS）」行，位置在首字延迟之后（对齐 DeepSeek 行序：模型用时 → 工具用时 → TTFT → TPS）。
- 数据源与底部状态条速度数字同源（`currentSpeed()`：turn 样本 3s 内新鲜 → 估算态，否则会话均）。
- 数字颜色与底部状态条速度数字一致：走 `speedColor()` 色阶，估算态同样呼吸动画。
- 无数据时显示 `--`（中性色），不编造。

### R3 速度色阶阈值压缩

- SPEED_ANCHORS 调整为 0 红 → 150 绿 → 300 蓝 → 500 紫（≥500 封顶），锚点色值不变，仅移动位置。
- 趋势图与所有 speedColor 消费方的域注释同步更新，不得残留 2000 口径。

### R4 速度趋势折线图重做

- 柱状图替换为 SVG 折线图：折线 + 面积渐变填充 + 数据点圆点。
- 折线描边用 SVG linearGradient 沿 x 轴按各采样点 `speedColor()` 取色，颜色语义与底部数字一致；数据点圆点同色。
- 带纵轴参考线与数值标注：顶部网格线标最大值、中部网格线标半值（10px 弱化文字），末点旁标注当前速度值（`N tok/s`）。
- 高度归一按本轮数据动态取 max（非固定 2000/500 域），保证小速度样本也有可见波动。
- 每个数据点保留 `<title>` tooltip（`N tok/s`）。
- 降级链不变：仅 1 个样本 → 只画点与数值标注；0 样本 → `暂无数据`。

## Out of Scope

- 不改底部状态条五 pill 的形态与顺序。
- 不改 session-stats.cjs 聚合口径与 speedTrend 数据形状（CONTRACT §4.2 不动）。
- 不引入任何图表库（延续零依赖、全自绘）。

## Acceptance Criteria

- [x] AC1 活动弹层含「输出速度（TPS）」行，数字颜色与底部速度数字同色（同速度下 hex 一致）；估算态呼吸一致。
- [x] AC2 弹层时长显示为 `X.X秒` / `X分Y秒` 格式，无裸秒数。
- [x] AC3 `speedColor(500)` 为紫色锚点色，`speedColor(2000)` 仍为紫色（封顶）；`tests/ramp.test.cjs` 全绿。
- [x] AC4 趋势图为折线图，含网格参考线、最大值/半值标注、末点数值标注；数据点颜色走 speedColor。
- [x] AC5 弹层底部无大面积空白（图表填充容器）。
- [x] AC6 `npm test` 全绿；`python3 core/sync_plugin.py --check` 无漂移（plugins 副本同步）。

## Risks

- SVG 按构建时容器像素宽定点，弹层宽度变化（如窗口缩放）不重排——弹层打开期间宽度稳定，可接受；重开弹层即重算。
- 锚点移动影响 ramp 单测中的字面量采样（2000 相关注释/样本），需同步更新避免误导。
