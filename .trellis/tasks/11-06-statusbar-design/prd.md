# ZCode 状态栏插件需求与方案

## Goal

构建 ZCode 客户端状态栏插件：在输入框下方以视觉化控件（图标 + 等宽数字 + 连续渐变色）呈现生成速度、累计 token、缓存命中、子代理状态，并以色阶增强官方上下文圆环；去除原插件的文字型提示，含义全部由视觉表达。技术原理与安装卸载复刻 `zcode-token-usage-statusbar`，视觉 UX 参考 `deepseek-harness` composer 统计条，字体对齐 ZCode 官方上下文样式。

本任务交付需求与设计文档，并按 implement.md 清单分阶段完成插件实现（2026-11-06 用户批准开工，实现纳入本任务范围）。

## Confirmed Facts（调研结论，详见 research/）

- ZCode 无正式 statusbar 插件接口；官方插件 UI 仅 MCP Apps 内联页/侧栏。（research/zcode-official-context.md）
- 原插件 UI 靠修改 app.asar 注入 + renderer 状态桥；数据源为只读 SQLite + 原生按钮 aria-label；速度色实际为离散十档、上下文为三色，均非连续渐变。（research/zcode-token-usage-statusbar.md）
- deepseek 统计条：输入框下方水平居中、图标+短读数、`tabular-nums`、预留高度防跳动、详情进点击弹层。（research/deepseek-harness-statusbar.md）
- 官方数字样式 = mono 栈 + `--text-ui-sm`（默认 12px）+ `foreground-subtle`；宿主向插件桥接 `--font-mono`、`--font-text-sm-size` 等变量。（research/zcode-official-context.md）
- 原插件卸载为反向剥离而非恢复备份；存在 3 个卸载闭环缺口（见 R8）。

## Requirements

- **R1 常驻控件**：输入框下方水平居中独立状态条，从左至右：Activity（轮次·步数·tok/s）、Usage（累计 token·缓存命中%）、子代理栏（双态，见 R5）、齿轮按钮（常驻）。上下文不重复画圆环（见 R4）。
- **R2 速度口径**：生成中 = 字符增量实时估算（约 2s 采样窗，按每 token 字符数换算并自校准）；完成后 = 会话加权平均（Σ输出 token ÷ Σ生成时长，200ms ≤ 窗口 < 1h，不含子代理）。展示标签用 tok/s。
- **R3 速度色阶**：数字颜色随速度连续插值（慢→快：红→绿→蓝→紫），数值微变颜色平滑变化；估算态与核实态同用一条色阶，但估算态须有可区分的视觉标识。
- **R4 上下文增强**：不新增第二个上下文指示；对官方上下文圆环叠加连续色阶（0% 绿 → 50% 黄 → 90% 红 → 100% 深红），并增强 hover/点击详情（已用/总量 mono 数字，复用官方面板数据口径：分母为完整 context window）。官方圆环缺席（如 Highspeed 锁定模型）时不显示。
- **R5 子代理栏双态**：有运行中子代理 → 图标 + 活跃数 + 实时速度（跟随速度色阶）；全部结束但本会话有子代理消耗 → 图标 + 会话累计 token（中性灰）。两态常驻，视觉可区分忙/闲。
- **R6 详情弹层**：Activity 点击 → 模型用时、工具用时、TTFT、速度趋势（最近一段/最近 10 轮）；Usage 点击 → 输入/输出/缓存读/缓存写分项与子代理明细。**无费用、无套餐余额**。
- **R7 齿轮短菜单**：四控件显示开关、立即刷新、复制诊断、重置会话统计、检查更新、版本号、卸载入口。全部短句，无长段说明。
- **R8 安装卸载**：复刻稳定运行目录、原子替换、hash 基线 + journal、热更新机制；启用即自动注入。补齐原插件三个卸载缺口：① 插件 remove 时调用引擎补丁 restore；② 更新 ZIP 预注入提供撤销链；③ asar 移除失败时不删除运行目录（不留悬空注入行）。卸载保留用户配置与统计数据。
- **R9 自动更新**：自动检查 Release，按渠道/版本/文件集/哈希校验后自动下载安装并热换；这是插件唯一联网触点。
- **R10 数据边界**：只读 SQLite + renderer 状态桥（含降级路径）；不读取账号凭据、不请求供应商接口；状态条身份不可确认的窗口/分栏不显示（防串数）。
- **R11 零会话干扰**：不做回答末尾统计行；不做 prompt-submit 向模型注入任何背景信息。
- **R12 视觉规格**：数字用官方 mono 字体栈与 `--text-ui-sm` 字号（随界面字号设置缩放），基色 `foreground-subtle`，`tabular-nums`；布局对齐 deepseek 规格（控件间 12px、图标 14×14、行高 20px、圆角 8px、hover 升亮、预留高度防跳动）；颜色语义经色阶表达，正文不留长文字。

## Out of Scope

- 费用估算、套餐/余额查询、价格表、汇率（及相应凭据读取）
- 回答末尾统计行、prompt-submit 模型注入
- Git 栏、重置卡、今日/项目累计等原插件其余常驻分区（Activity/Usage 弹层内也不含项目累计）
- MCP Apps 页面形态；CLI（终端）侧状态显示
- 引擎行为改动的功能扩展（引擎补丁仅按原样复刻以保持兼容）

## Risks / Deferred

- 宿主升级耦合（DOM/store/锚点/schema 变动）为继承性风险，靠版本登记与降级显示缓解（design.md）。
- 估算速度非精确 TPS，须保留估算态视觉标识（R3）与文档措辞约束（CONTEXT.md）。
- 实机验收项（真实 hover、多窗口、Windows 文件占用）无法被 stub 测试覆盖，列入实现任务的人工验收清单。
