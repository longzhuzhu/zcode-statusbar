# 思维指南

> **目的**：写代码前把「没想到」变成「想到了」。
>
> 大部分 bug 与技术债来自「没想到」：没想到层边界 → 跨层 bug；没想到模式重复 → 处处复制；没想到边界条件 → 运行时错误。

---

## 可用指南

| 指南 | 用途 | 何时读 |
|---|---|---|
| [代码复用思维指南](./code-reuse-thinking-guide.md) | 识别既有单点、减少重复 | 写新代码前；发现模式重复时 |
| [跨层数据流思维指南](./cross-layer-thinking-guide.md) | 想清数据跨层流动与契约 | 功能跨 2+ 层；改字段/事件/协议时 |

## 触发器速查

### 何时想跨层问题

- [ ] 改动涉及全局名/事件名/数据形状（CONTRACT.md 管辖）
- [ ] 改 Node↔Python 协议、白名单清单、文件命名
- [ ] 新增数据通路（SQLite → 聚合 → 渲染）
- [ ] 不确定逻辑该放哪一层

→ 读 [跨层数据流思维指南](./cross-layer-thinking-guide.md)

### 何时想复用问题

- [ ] 要写的东西似曾相识
- [ ] 同一模式出现 3+ 次
- [ ] 要改常量/清单/配置
- [ ] 要改名（联动面 + 残留清理）
- [ ] 两个文件读同一个非共享真值

→ 读 [代码复用思维指南](./code-reuse-thinking-guide.md)

## 修改前铁律

> **改任何值之前，先搜！**

```bash
rg "value_to_change" core/ statusbar/ zusage.py
```

本仓库的联动重灾区：白名单双侧（`runtime_lock.py` ≡ `release_unpack.py`）、CONTRACT.md 八个全局名、注入顺序、`zcstatusbar` 前缀族文件名。

## 如何使用本目录

1. **编码前**：扫一眼相关指南
2. **编码中**：觉得重复/复杂时回来查
3. **出 bug 后**：把新教训回填到对应指南（附文件出处）
